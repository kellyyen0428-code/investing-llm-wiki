# 符號表

全 wiki 統一使用的符號（使用這些符號的公式見[公式總表](formula-sheet.md)）。原始資料用不同符號時，wiki 內文一律改用本表的符號，並在下方「各資料符號對照」記錄差異。

> [!note] 補充說明（非課程資料）
> 下表是建立 wiki 時預設的常見符號，匯入第一份課程資料後，會改成以老師或課本的用法為主。

## 統一符號

| 符號 | 意義 | 備註 |
|---|---|---|
| $r_i$ | 資產 $i$ 的報酬率 | |
| $E(r_i)$ | 資產 $i$ 的期望報酬率 | |
| $r_f$ | 無風險利率 | |
| $r_M$ | 市場投資組合報酬率 | |
| $\sigma_i$ | 資產 $i$ 報酬率的標準差 | |
| $\sigma_i^2$ | 資產 $i$ 報酬率的變異數 | |
| $\mathrm{Cov}(r_i, r_j)$ 或 $\sigma_{ij}$ | 共變異數 | |
| $\rho_{ij}$ | 相關係數 | |
| $\beta_i$ | 資產 $i$ 的 Beta | |
| $w_i$ | 資產 $i$ 在投資組合中的權重 | |
| $p$（下標） | 投資組合 | 例：$E(r_p)$、$\sigma_p$ |
| $A$ | 風險趨避係數 | |
| $\alpha_i$ | 資產 $i$ 的 Alpha | |
| $F$ | 面額（face value） | L02 |
| $P$ | 價格 | L02 |
| $n$ | 距到期天數 | L02（講義用 $t$，見下方對照） |
| $i$ | 銀行折現率（bank discount yield） | L02 |
| $r_{BEY}$ | 債券等值收益率（bond-equivalent yield） | L02 |
| $t$ | 邊際稅率 | L02 |
| $r_{\text{taxable}}$、$r_{\text{tax-exempt}}$ | 應稅收益率、免稅收益率 | L02 |
| $D$ | 每股股利 | L02 |
| $P_{\text{buy}}$、$P_{\text{sell}}$ | 買進價格、賣出價格 | L02 |
| $d$ | 價格加權指數的除數（divisor） | L02 |
| IMR | 期初保證金比例（initial margin requirement） | L03 |
| MMR | 維持保證金比例（maintenance margin requirement） | L03 |
| $\text{NAV}_0$、$\text{NAV}_1$ | 期初、期末的淨資產價值 | L04 |
| HPR | 持有期間報酬率（holding-period return） | L05 |
| $r_t$、$\bar{r}$ | 第 $t$ 期報酬率、樣本平均報酬率 | L05 |
| $r_G$ | 幾何平均（時間加權）報酬率 | L05 |
| IRR | 內部報酬率（金額加權平均報酬） | L05 |
| APR、EAR | 年百分率、有效年利率 | L05 |
| $n$ | **每年複利次數** | L05；L02 的 $n$ 是距到期天數，依章節區分 |
| $R$ | 名目利率 | L05 |
| $r$（無下標） | 實質利率 | L05；有下標的 $r_i$、$r_p$ 仍是報酬率 |
| $i$ | **通貨膨脹率** | L05；L02 的 $i$ 是銀行折現率，依章節區分（使用者決定兩者都用 $i$） |
| $E(i)$ | 預期通膨率 | L05 |
| $p(s)$、$r(s)$ | 情境 $s$ 的機率與報酬 | L05 |
| $sr_i$ | 標準化分數（離平均數幾個標準差） | L05 |
| VaR | 風險價值（Value at Risk）；不是變異數 | L05 |
| $S_p$ | 投資組合 $p$ 的夏普比率 | L05 |
| $y$ | 投資在風險性投資組合的比例 | L05 |
| $C$（下標） | 完整投資組合（complete portfolio） | L05，例：$E(r_C)$、$\sigma_C$ |
