# 初級市場 vs 次級市場（Primary vs Secondary Market）

| | 初級市場（Primary Market） | 次級市場（Secondary Market） |
|---|---|---|
| 交易內容 | **初次發行**有價證券 | **已公開發行**有價證券的買賣 |
| 主要參與的中介機構 | 投資銀行（專長在初級市場交易） | — |

（來源：[L01](../sources/L01-investment-environment.md) 投影片 24）

> [!note] 補充說明（非課程資料）
> 初級市場的資金從投資人流向發行證券的公司；次級市場則是投資人之間互相轉手，公司不會因此拿到新的資金。例如 IPO 屬於初級市場，平常在證券交易所買賣股票屬於次級市場。

## L03 的補充

| | 初級市場 | 次級市場 |
|---|---|---|
| 發生什麼事 | 新證券被創造、賣出 | 既有持有人賣給另一方 |
| 發行公司拿到錢嗎？ | **拿到**（關鍵差別） | 拿不到，也不直接參與 |
| 方式 | 公開發行（向 SEC 登記、賣給大眾）或私募（不登記、只賣給少數投資人、有轉售限制） | 透過各種交易機制成交 |
