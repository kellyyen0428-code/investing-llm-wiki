# 基金的費用與稅（Fund Costs and Taxation）

## 一句話定義

投資共同基金要付的各種費用，會**直接吃掉淨值的累積**；費用結構不同，長期結果差很多。（來源：[L04](../sources/L04-mutual-funds.md) 投影片 19–23）

## 四種費用（投影片 19–20）

| 費用 | 什麼時候付 | 水準 |
|---|---|---|
| 營運管理費（Operating expenses） | 每年，以基金總資產的百分比計算；包括經理人的管理費、顧問費 | ETF 平均 0.07%，一般基金 0.74% |
| 銷售手續費／前收費用（Front-end load） | 買基金時，從投資款項先扣除 | 通常 3%–6%，最高不能超過 8.5% |
| 贖回手續費／後收費用（Back-end load） | 贖回時 | — |
| 12b-1 費用 | 每年，由淨值支應廣告、促銷文宣、經紀商佣金等配銷成本 | 每年最高不超過 1% |

管理型投資公司的管理費約為資產價值的 0.2%–1.5%。（來源：[L04](../sources/L04-mutual-funds.md) 投影片 7）

### 同一檔基金的不同級別（投影片 22）

2019 年 Dreyfus High Yield Fund：

| | Class A | Class C | Class I |
|---|---|---|---|
| 前收費用 | 4.50% | 0 | 0 |
| 後收費用 | 0 | 1% | 0 |
| 12b-1 費用 | 0.25% | 1.0% | 0 |
| 費用率 | 0.7% | 0.7% | 0.7% |

前收費用和 12b-1 費用之間有取捨。

## 費用怎麼影響累積績效（Table 4.2，投影片 21、23）

三檔基金毛報酬都是每年 10%，投資 1 萬美元 20 年後：低費用的 A 基金 64,282 美元，費用率較高的 B 基金 53,529 美元，有前收費用的 C 基金 54,649 美元。→ [例題](../examples/fund-fees-01.md)

## 基金報酬率（投影片 24）

$$\text{報酬率} = \frac{\text{NAV}_1 - \text{NAV}_0 + \text{股息} + \text{資本利得分配}}{\text{NAV}_0}$$

$\text{NAV}_0$、$\text{NAV}_1$ 為期初與期末的淨資產價值。→ [投資公司與淨值](investment-companies.md)

### 柔性資金（Soft dollars）

基金經理人委託特定經紀商交易，經紀商替基金公司負擔資料庫、軟體、報價系統等費用；基金公司可能用頻繁交易的手續費作為回報。這讓投資人很難精確衡量基金的真實費用。（來源：[L04](../sources/L04-mutual-funds.md) 投影片 24）

## 稅與周轉率（投影片 25）

- **移轉性**（pass-through status）：基金只要把大部分收益分配給投資人，稅款就由投資人而不是基金本身負擔。
- **周轉率**（turnover）＝交易量 ÷ 總資產，衡量投資組合每年更替的程度。高周轉率的基金，會讓投資人的稅務規劃沒有效率。
