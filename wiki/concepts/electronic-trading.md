# 電子交易的崛起（The Rise of Electronic Trading）

## 一句話定義

證券交易從人工撮合轉向電腦網路自動交易，結果是**買賣價差降低**。（來源：[L03](../sources/L03-securities-markets.md) 投影片 17）

## 市場變革年表（投影片 17–18）

| 年份 | 事件 |
|---|---|
| 1969 | 第一個 ECN——Instinet 成立 |
| 1975 | NYSE 取消固定佣金；國會修法建立全國市場系統（NMS） |
| 1994 | NASDAQ 醜聞；之後 SEC 訂定新的委託處理規則、NASDAQ 把 ECN 報價納入顯示、SEC 通過另類交易系統規則（讓 ECN 可以登記為交易所） |
| 1997 | 最小跳動單位從 1/8 美元降為 1/16 美元 |
| 2000 | 全國證券商協會（NASD）與 NASDAQ 分家 |
| 2001 | 最小跳動單位降為 0.01 美元 |
| 2006 | NYSE 收購 Archipelago，改名 NYSE Arca；SEC 通過 NMS 規則，要求各交易所尊重其他交易所的報價 |

## 跳動單位越小，價差越小（Figure 3.6，投影片 19）

1993–2003 年的有效價差：1/8 制度時約 0.12 美元，1/16 制度時約 0.08–0.09 美元，十進位制度後降到約 0.03 美元（依圖目測）。

## 新型交易型態（投影片 22）

| 型態 | 說明 |
|---|---|
| 演算法交易 | 用寫好程式的交易策略，決定下單的時機、價格與數量 |
| 高頻交易 | 透過電腦程式高速買賣證券，賺取買賣價差 |
| 黑池交易 | 大宗股票交易時，買賣雙方匿名撮合 |
| 大宗交易（Blocks） | 至少 10,000 股的交易 |

簡報另列「債券交易」一項，未展開說明。
