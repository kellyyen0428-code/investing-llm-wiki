# 實質資產與金融資產（Real Assets vs Financial Assets）

## 一句話定義

- **實質資產（Real Assets）**：用來創造財貨和提供服務的資產，例如廠房、機器設備。
- **金融資產（Financial Assets）**：對實質資產本身或其收益的**求償權**，例如股票、債券。

（來源：[L01](../sources/L01-investment-environment.md) 投影片 4）

## 直覺解釋

- 實質資產決定一個經濟體**能生產多少東西**。
- 金融資產決定這些產出**分給誰**。

> [!note] 補充說明（非課程資料）
> 上面兩句是常見的記憶方式：實質資產是「餅」，金融資產是「分餅的權利」。

## 金融資產與金融負債互相抵銷

- 每一筆金融資產（求償權）背後，都有一筆等額的金融負債（發行的證券）。
- 例：個人買 Toyota 的債券，對個人是金融資產，對 Toyota 是金融負債，兩者加總後抵銷。
- 所以把整個經濟體的資產與負債加總後，**只剩下實質資產**；經濟體的淨值等於所有實質資產的總和。

（來源：[L01](../sources/L01-investment-environment.md) 投影片 6）

→ 常見誤解見[金融資產不會增加經濟體的淨值](../pitfalls/financial-assets-and-national-wealth.md)

## 簡報資料重點（美國，2019 年）

| 表 | 重點 | 投影片 |
|---|---|---|
| Table 1.1 美國家計單位資產負債表 | 總資產約 124.7 兆美元；實質資產占 28.7%（主要是不動產 23.7%），金融資產占 71.3%（最大項為退休金準備 21.2%、公司股權 14.0%）；負債占 12.9%，淨值占 87.1%。 | 5 |
| Table 1.2 美國國內資產淨額 | 合計約 69.7 兆美元，**全部是實質資產**：住宅不動產最多，其次是商業不動產、設備與智慧財產、耐久消費財、存貨。這張表印證「經濟體淨值＝實質資產總和」。 | 7 |
| Table 1.3 美國金融機構資產負債表 | 實質資產只占 1.0%，金融資產占 92.4%；負債以存款為主（77.0%），淨值只占 11.4%。 | 26 |
| Table 1.4 美國非金融企業資產負債表 | 實質資產占 52.4%、金融資產占 47.6%；淨值占 56.4%。 | 27 |

觀察：家計單位以持有金融資產為主；金融機構幾乎只有金融資產；非金融企業才持有大量實質資產（廠房、設備、存貨）。
