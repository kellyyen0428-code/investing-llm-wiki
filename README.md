# 投資學 LLM Wiki

一個由 LLM（Claude Code）持續撰寫與維護的**投資學課程學習知識庫**，參考 Andrej Karpathy 提出的「LLM Wiki」做法：不是每次提問都從原始講義重新檢索，而是讓 LLM 把讀過的資料**整理成互相連結的 Markdown 頁面**，知識會隨著匯入的講義越來越完整。

## 連結

| 項目 | 網址 |
|---|---|
| 章節首頁（HTML 教學簡報） | https://kellyyen0428-code.github.io/investing-llm-wiki/ |
| Wiki 目錄 | [wiki/index.md](wiki/index.md) |
| 簡報產生 graph（流程設計） | [workflows/slide-graph.md](workflows/slide-graph.md) |
| 一次實際執行紀錄（範例：第 5 章） | [outputs/runs/2026-11-22-ch05/run-log.md](outputs/runs/2026-11-22-ch05/run-log.md) |

> 原始講義（`raw/`）是老師的課程簡報，含課本出版社的版權圖表，因此**沒有放進公開的 repo**；wiki 只保留整理後的摘要並標註投影片編號。

## 主題與目的

- **主題**：投資學（課程講義：張元晨老師，共六個單元）
- **用途**：學習與考前複習——概念整合、易錯點整理、比較表、課程地圖
- **延伸應用**：用 wiki 的內容，透過一個有檢查點的 **graph 流程**產生親切好讀的手帳風 HTML 教學簡報

## 架構

```
LLM Wiki notes/
├── CLAUDE.md            給 LLM 的維護規則（schema）
├── raw/                 原始資料（唯讀，因版權未上傳到 GitHub）
├── wiki/                LLM 撰寫的知識庫
│   ├── index.md         全部頁面的目錄
│   ├── overview.md      課程地圖
│   ├── log.md           每次匯入、問答、修改的紀錄
│   ├── sources/         每份講義的摘要
│   ├── concepts/        概念頁（例如代理人問題、CDO）
│   ├── comparisons/     比較頁（例如消極型 vs 積極型）
│   ├── pitfalls/        易錯點（例如系統風險 vs 系統性風險）
│   └── ……
├── workflows/           產生簡報的 graph 流程規格與版型庫
└── outputs/             由 wiki 產出的成品
    ├── slides/          HTML 簡報
    └── runs/            每次執行 graph 的中間檔與檢查紀錄
```

三層分工：

| 層 | 內容 | 誰負責 |
|---|---|---|
| 原始資料 `raw/` | 老師的 PDF 講義 | 使用者提供，LLM 只讀不改 |
| 知識庫 `wiki/` | 摘要、概念、比較、易錯點、索引 | LLM 撰寫與維護 |
| 規則 `CLAUDE.md` | 頁面格式、連結、出處、工作流程 | 使用者與 LLM 共同訂定 |

## 主要規則

- **只用課程資料**，不上網補充；LLM 自己補充的說明一律標「補充說明（非課程資料）」。
- **每個主張都附出處**，標到講義的投影片編號。
- 發現資料不一致（例如講義寫沙賓法案 2000 年通過，一般認為是 2002 年）時，照講義寫並標註，交給使用者確認。
- 一次匯入一份講義，先和使用者討論重點再寫頁面。

## 工作流程

| 流程 | 做什麼 |
|---|---|
| Ingest（匯入） | 讀一份講義 → 討論重點 → 寫摘要、概念、比較、易錯點 → 更新目錄、課程地圖、紀錄 |
| Query（問答） | 先讀目錄找頁面再回答；有價值的答案經同意後存回 wiki |
| Lint（健康檢查） | 檢查矛盾、孤兒頁、失效連結、待建頁面 |
| Outputs（產出簡報） | 依 [workflows/slide-graph.md](workflows/slide-graph.md) 的 graph 流程產生 HTML 簡報 |

## 怎麼閱讀

- **Obsidian**：用 Obsidian 開啟整個資料夾，從 `wiki/index.md` 開始瀏覽，或打開關聯圖（Graph view）看概念之間的連結。
- **一般編輯器或 GitHub**：所有連結都是標準 Markdown 相對路徑，直接點就能跳頁。
- **簡報**：打開上方的章節首頁網址（或本機的 `index.html`），點選各章卡片進入簡報，← → 翻頁。線上版簡報的出處連結會開到 GitHub 上的 wiki 頁面。
